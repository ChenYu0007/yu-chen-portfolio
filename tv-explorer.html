01 / THE PURPOSE

What I wanted to build

Find television shows and keep a personal list of favourites.

02 / KEY FEATURES

What the application does

  • Search shows using the TVMaze API
  • Add and remove favourites
  • Synchronize favourites through Firestore
  • Sort saved shows and remember the theme

03 / DEVELOPMENT

Connecting the workflow

I connected an external API to a React interface, then added Firestore to keep favourites available after a refresh. This project helped me understand state, asynchronous requests, and real-time data.

  1. Search for a show
  2. Review the results
  3. Save a favourite
  4. Return to the favourites list

04 / REFLECTION

What comes next

Instructor feedback highlighted component organization, search debouncing, and a loading state for favourites as useful next improvements.
